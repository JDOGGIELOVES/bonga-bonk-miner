# Bonga Bonk Miner ✌️🔨

Standalone tap-to-mine game featuring Bonga Bonk's Sister. Mine $BONGA, connect your Solana wallet, and claim rewards.

## Quick Start

```bash
npm install --ignore-scripts --legacy-peer-deps
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- Tap anywhere to bonk meme coins
- 100 bonks = 1 $BONGA (max 10/day)
- Solana wallet connect (Phantom, Solflare)
- Claim mined $BONGA (simulated)
- Sound effects + lo-fi music
- NFT whitelist perks for Bonk Miner players

## Environment

See `.env.example` for RPC and mint configuration.
