Bonga NFT Trait Art — 16 unique poses & activities
=================================================

Each PNG is a unique Bonga character doing a different activity aligned with the Bonga way:
peace, bonk, hippie vibes, and cosmic chill.

Files map to traits in src/lib/nft-trait-poses.ts

To regenerate or refine art, use the base character reference at public/bonga-character.png
and public/characters/IMAGE_PROMPT.txt for consistent traits (dreads, headband, joint, $BONGA).

Run: npm run nft:setup for on-chain deploy checklist.
